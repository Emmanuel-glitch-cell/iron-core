# Iron Core

**Iron Core** es una landing page moderna enfocada en fitness y alto rendimiento. Presenta servicios de entrenamiento, productos deportivos y un sistema de contacto, todo con un diseño responsive y enfoque mobile-first.

---

## Características
* **Diseño responsive**: Enfoque mobile-first.
* **Estructura semántica**: Uso correcto de HTML5.
* **Navegación fluida**: Implementación de `scroll-behavior`.
* **Menú hamburguesa**: Funcional únicamente con CSS.
* **Layout avanzado**: Uso de CSS Grid y Flexbox.
* **Variables CSS**: Configuración en `:root` para un diseño escalable.
* **Secciones organizadas**:
    * Hero
    * Servicios
    * Productos
    * Servicios personalizados
    * Beneficios
    * Contacto
* **Formulario de contacto**: Estructura básica funcional.
* **Optimización SEO**: Inclusión de meta tags y Open Graph.

---

## Tecnologías usadas
* **HTML5**
* **CSS3**
* **Font Awesome** (Iconos)
* **Vercel** (Deploy)
